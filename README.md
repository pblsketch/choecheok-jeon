# 최척전 — (가제) 두 개의 항로

**만든이**: 박준일 (온양여자고등학교 국어 교사)

조위한 「최척전」을 바탕으로 한 고등학생용 고전문학 학습 게임입니다. 학생은 옥영이 되어 정유재란으로 흩어진 남편 최척을 찾아 조선·일본·중국·안남을 떠돌고, 모든 길은 안남 포구의 퉁소 재회로 모입니다.

> 지금은 **기획 단계**입니다. 코드는 아직 없습니다.
