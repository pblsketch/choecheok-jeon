# 음원 이용 조건과 받을 파일 (T5 퉁소와 배경음)

조사한 날: 2026-10-07. 내려받기를 마친 날: 2026-10-08(아래 2·3). 조건: 지학사에 상업 납품할 수 있어야 한다(spec §9). 공공누리 제1유형, CC0, CC BY, 퍼블릭 도메인만 쓴다. 비상업(NC)·변경금지(ND)·조건이 불분명한 것은 쓰지 않는다.

## 1. 국립국악원 「디지털 이음」 — 이용 조건 확인

- 주소: https://www.gugak.go.kr/digitaleum/ (→ `/digitaleum/front/main.do`)
- 단음 다운로드 `/digitaleum/front/monotone/list.do`, 악구 다운로드 `/digitaleum/front/phrase/list.do`, 확장 다운로드 `/digitaleum/front/extend/list.do` 세 쪽 모두 아래에 같은 글이 있다(2026-10-07에 쪽 원문을 받아 확인).
  > 국립국악원이 창작한 이 저작물은 공공누리 출처표시 조건에 따라 이용 할 수 있습니다.
  > "공공누리 제1유형(출처표시)" 조건에 따라 이용할 수 있습니다. (링크: http://www.kogl.or.kr/open/info/license_info/by.do)
- 악기마다 매긴 공공누리 유형: 단음 다운로드의 악기 목록(`/digitaleum/front/monotone/getInstrumentList.do`)이 악기마다 `instrNuryTyp` 값을 돌려준다. **퉁소(instrCd 19869)·단소(19860)·소금(19991) 모두 `1`(제1유형)**.
- 공공누리 제1유형(출처표시): 출처를 밝히면 상업적 이용과 변경(2차적 저작물 작성)이 모두 된다 → 납품 가능.
- 내려받기: 로그인은 없다. 다만 내려받기 단추를 누르면 **사용목적(상업용/비상업용), 사용용도(교육용·어플리케이션 제작·음악 제작·연구용·기타), 기관명(소속)**을 적는 창이 뜨고, 이것을 적어야 파일을 준다. 이 값은 이용자가 직접 밝히는 내용이라 만든이가 정했다: **사용목적 상업용, 사용용도 어플리케이션 제작, 기관명 온양여자고등학교**(2026-10-08, 아래 2·3).
- 연주자: 사이트의 악구 정보(곡명·유파·장단·조·BPM)에 연주자 이름은 없다. 크레딧에는 "연주자 표기 없음(국립국악원 제작 음원)"으로 적었다.

**해결(2026-10-08)**: 영웅의 길은 내려받기 창에 사용목적 **비상업용**·용도 **교육용**을 적었다(영웅소설 `design/bgm_plan.md`). 이용 조건 자체는 공공누리 제1유형이라 상업 이용이 허락되어 있지만, 납품 기록을 맞추려고 같은 악구 63개를 **사용목적 '상업용'으로 다시 받았다**.

- 받은 도구: `python tools/fetch_digitaleum.py` — `tools/make_bgm.py`의 `TRACKS`에서 악구 코드를 읽어 `assets/raw_audio/<폴더>/`에 받는다. 창에 적는 값의 기본값이 사용목적 `상업용`, 사용용도 `어플리케이션 제작`, 기관명 `온양여자고등학교`다(`--purpose`·`--use`·`--org`로 바꿀 수 있다).
- 다시 만들기: `python tools/make_bgm.py` → 9곡이 이전 파일과 바이트까지 같았다(같은 원음·같은 손질). `credits/audio.tsv`의 출처 칸에 다시 받은 날과 창에 적은 값을 적었다.

## 3. 퉁소 — 받아서 넣었다(2026-10-08)

디지털 이음 단음 다운로드 → 관악기 → 퉁소(공공누리 제1유형)에서 아래 파일을 받았다. 내려받기 창에 적은 값: 사용목적 **상업용**, 사용용도 **어플리케이션 제작**, 기관명 **온양여자고등학교**.

| 구분 | 이름 | 파일 | 쓰임 |
|---|---|---|---|
| 연주 | **애원성** | `Tungso_8.wav` (mntnSeq 2405) | **게임에 씀** — 안남 장면의 퉁소 가락 |
| 시김새 | 북청 평취 A | `Tungso_6.wav` (mntnSeq 2403) | 받아 두기만 함(게임에는 쓰지 않음) |
| 시김새 | 북청 A♭ | `Tungso_7.wav` (mntnSeq 2404) | 받아 두기만 함(게임에는 쓰지 않음) |

- 원음은 `assets/raw_audio/tongso/`(저장소에 올리지 않는 폴더)에 있다.
- `python tools/make_tongso.py`로 `assets/sfx/tongso.mp3`(앞뒤 무음 줄임, 숨 쉬는 틈에서 13초로 자름, -16 LUFS, 모노 64kbps)와 `assets/sfx/tongso_data.js`(파일로 열 때 쓰는 base64)를 만들고, `js/data/bgm.js`의 `tongso:` 줄이 바뀌었다(`BGM.tongso`).
- `credits/audio.tsv`에 두 줄을 넣었다(출처 칸에 받은 날과 창에 적은 값). 게임 안 출처 화면과 이야기 수첩의 퉁소 줄은 `bgm.js`를 읽어 실제 연주로 바뀌었다.
- 합성 퉁소음은 파일을 읽지 못할 때만 쓰는 대체 소리로 남았다(아래 5).
- 다시 만들 때: 원음을 `assets/raw_audio/tongso/`에 넣고 `python tools/make_tongso.py` → `cd tests && node audio.mjs && node content.mjs`.

### 퉁소를 받을 수 없을 때(대신할 악기)

디지털 이음의 같은 조건(공공누리 제1유형) 안에서 가까운 관악기 순서로: **단소**(단음 다운로드 instrCd 19860, 악구 다운로드 '단소' — 풍류·민요·잡가), 그다음 **소금**(19991), **대금**. 이렇게 바꾸면 `python tools/make_tongso.py --src <파일> --instrument 단소 --from "…"`로 만들고, `BGM.tongso.instrument`가 '단소'가 되어 이야기 수첩·크레딧에 "퉁소 대신 단소 연주"라고 밝힌다(spec §9).

## 5. 합성음(대체용)

- 배경음: 파일이 없거나 못 읽으면 `js/data/bgm.js`의 `synth`에 적은 합성 곡(`js/core/audio.js`의 TRACKS, 같은 만든이의 「영웅의 길」 합성 엔진)으로 바꿔 튼다.
- 퉁소: 실제 연주 파일(`assets/sfx/tongso.mp3`)이 없거나 못 읽으면 합성 퉁소음(계면조 가락, 대금 소리에 굵은 숨소리와 청 울림을 더함)을 같은 또렷함·방향 처리로 튼다. 자체 합성이라 파일·이용 조건이 따로 없다.
- 효과음(종이 넘김·물결·바람·모닥불·게이지 오름/내림): 모두 브라우저에서 합성한다(파일 없음).
