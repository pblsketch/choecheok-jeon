# 음원 이용 조건과 받을 파일 (T5 퉁소와 배경음)

조사한 날: 2026-10-07. 조건: 지학사에 상업 납품할 수 있어야 한다(spec §9). 공공누리 제1유형, CC0, CC BY, 퍼블릭 도메인만 쓴다. 비상업(NC)·변경금지(ND)·조건이 불분명한 것은 쓰지 않는다.

## 1. 국립국악원 「디지털 이음」 — 이용 조건 확인

- 주소: https://www.gugak.go.kr/digitaleum/ (→ `/digitaleum/front/main.do`)
- 단음 다운로드 `/digitaleum/front/monotone/list.do`, 악구 다운로드 `/digitaleum/front/phrase/list.do`, 확장 다운로드 `/digitaleum/front/extend/list.do` 세 쪽 모두 아래에 같은 글이 있다(2026-10-07에 쪽 원문을 받아 확인).
  > 국립국악원이 창작한 이 저작물은 공공누리 출처표시 조건에 따라 이용 할 수 있습니다.
  > "공공누리 제1유형(출처표시)" 조건에 따라 이용할 수 있습니다. (링크: http://www.kogl.or.kr/open/info/license_info/by.do)
- 악기마다 매긴 공공누리 유형: 단음 다운로드의 악기 목록(`/digitaleum/front/monotone/getInstrumentList.do`)이 악기마다 `instrNuryTyp` 값을 돌려준다. **퉁소(instrCd 19869)·단소(19860)·소금(19991) 모두 `1`(제1유형)**.
- 공공누리 제1유형(출처표시): 출처를 밝히면 상업적 이용과 변경(2차적 저작물 작성)이 모두 된다 → 납품 가능.
- 내려받기: 로그인은 없다. 다만 내려받기 단추를 누르면 **사용목적(상업용/비상업용), 사용용도(교육용·어플리케이션 제작·음악 제작·연구용·기타), 기관명(소속)**을 적는 창이 뜨고, 이것을 적어야 파일을 준다. 이 값은 이용자가 직접 밝히는 내용이라 대신 적지 않았다(아래 3).
- 연주자: 사이트의 악구 정보(곡명·유파·장단·조·BPM)에 연주자 이름은 없다. 크레딧에는 "연주자 표기 없음(국립국악원 제작 음원)"으로 적었다.

## 3. 퉁소 — 선생님께 부탁드릴 것

디지털 이음에 **실제 퉁소 연주가 있다**(단음 다운로드 → 관악기 → 퉁소, 공공누리 제1유형). 내려받기 창(사용목적·기관명)은 선생님이 직접 적어야 하므로, 아래 파일을 받아 주시면 바로 넣는다. 그때까지 게임은 **합성 퉁소음**으로 끝까지 진행된다.

1. https://www.gugak.go.kr/digitaleum/front/monotone/list.do 를 연다.
2. 왼쪽 '관악기'에서 **퉁소**를 누른다.
3. 아래 파일에 체크하고 '선택 다운로드'(또는 줄마다 '다운로드'):

   | 구분 | 이름 | 파일 | 필요 |
   |---|---|---|---|
   | 연주 | **애원성** | `Tungso_8.wav` (mntnSeq 2405) | **꼭** — 안남 장면의 퉁소 가락으로 쓴다 |
   | 시김새 | 북청 평취 A | `Tungso_6.wav` (mntnSeq 2403) | 있으면 좋음(짧은 소리) |
   | 시김새 | 북청 A♭ | `Tungso_7.wav` (mntnSeq 2404) | 있으면 좋음(짧은 소리) |

4. 창에 적을 값(선생님이 정해 주세요): 사용목적 **상업용**(지학사 납품이므로 권장), 사용용도 **어플리케이션 제작** 또는 **교육용**, 기관명(소속).
5. 받은 파일(zip이면 풀어서)을 **`assets/raw_audio/tongso/`** 에 넣는다(저장소에는 올리지 않는 폴더).
6. 그다음 할 일(작업자): `python tools/make_tongso.py` → `assets/sfx/tongso.mp3`·`assets/sfx/tongso_data.js`가 생기고 `js/data/bgm.js`의 `tongso:` 줄이 바뀐다. `credits/audio.tsv`에 아래 두 줄을 넣고 `cd tests && node audio.mjs`로 점검한다.

   ```
   assets/sfx/tongso.mp3	국립국악원 「디지털 이음」 단음 다운로드(https://www.gugak.go.kr/digitaleum/front/monotone/list.do) — 퉁소 연주 '애원성'(Tungso_8.wav); 연주자: 사이트에 표기 없음(국립국악원 제작 음원)	공공누리 제1유형(출처표시) — 상업적 이용·변경 가능, 출처 표시 필요	앞뒤 무음 줄임, 20초 안의 숨 쉬는 틈에서 자름, 처음 30ms·끝 0.6초 서서히, -16 LUFS, 모노 64kbps mp3(tools/make_tongso.py)
   assets/sfx/tongso_data.js	위 tongso.mp3와 같은 소리(같은 출처)	공공누리 제1유형(출처표시) — 상업적 이용·변경 가능, 출처 표시 필요	tongso.mp3를 base64로 담은 것(file://로 열 때 씀, tools/make_tongso.py)
   ```

### 퉁소를 받을 수 없을 때(대신할 악기)

디지털 이음의 같은 조건(공공누리 제1유형) 안에서 가까운 관악기 순서로: **단소**(단음 다운로드 instrCd 19860, 악구 다운로드 '단소' — 풍류·민요·잡가), 그다음 **소금**(19991), **대금**. 이렇게 바꾸면 `python tools/make_tongso.py --src <파일> --instrument 단소 --from "…"`로 만들고, `BGM.tongso.instrument`가 '단소'가 되어 이야기 수첩·크레딧에 "퉁소 대신 단소 연주"라고 밝힌다(spec §9).

## 4. 다른 곳도 찾아본 결과

- Wikimedia Commons: 'tungso', 'tongso', '퉁소', 'danso', '단소', 'Korean flute'로 오디오 파일을 찾았으나 퉁소·단소 연주는 없었다(2026-10-07, Commons API 검색).
- freesound: 내려받기에 로그인이 필요해 자동으로 받을 수 없다. 디지털 이음에 조건이 확실한 실제 퉁소가 있으므로 더 찾지 않았다.

## 5. 합성음(대체용)

- 배경음: 파일이 없거나 못 읽으면 `js/data/bgm.js`의 `synth`에 적은 합성 곡(`js/core/audio.js`의 TRACKS, 같은 만든이의 「영웅의 길」 합성 엔진)으로 바꿔 튼다.
- 퉁소: 파일이 없거나 못 읽으면 합성 퉁소음(계면조 가락, 대금 소리에 굵은 숨소리와 청 울림을 더함)을 같은 또렷함·방향 처리로 튼다. 자체 합성이라 파일·이용 조건이 따로 없다.
- 효과음(종이 넘김·물결·바람·모닥불·게이지 오름/내림): 모두 브라우저에서 합성한다(파일 없음).
