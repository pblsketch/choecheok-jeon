# 화풍 시안

게임 삽화의 화풍을 고르기 위해 **같은 장면 하나를 네 가지 화풍으로** 그렸다.

- 장면: **안남 포구의 밤** — 17세기 안남(베트남) 국제 무역항(호이안 비슷한 곳). 명나라 정크선, 일본 주인선, 동남아 배들이 고요한 밤바다에 정박해 있고, 보름달이 물 위에 낮게 떠 있으며 안개가 깔려 있다. 일본 배 갑판에는 남장한 옥영(조선 평민 남자 옷차림)이 가슴에 손을 얹고 귀를 기울이고, 건너편 중국 배에서는 명나라 옷을 입은 최척이 퉁소를 분다. 소리는 물 위에 번지는 잔물결로만 은은하게 나타냈다.
- 그림 안에는 글자·낙관·서명이 들어가지 않게 했다.
- 만든 도구: Codex CLI 이미지 생성(`tools/gen.ps1`). 프롬프트는 `tools/prompts/style_*.txt`에 있다.
- 1536×1024로 요청했지만 생성 도구가 더 넓은 가로 그림(1774×887, 그림책풍은 1672×941)으로 돌려주었다. 화풍을 고르는 데에는 지장이 없다.

| 기호 | 파일 | 화풍 | 특징 |
|---|---|---|---|
| 가 | `style_woodblock.png` | 목판 삽화풍 | 조선 후기 방각본 소설 삽화처럼 굵은 먹선에 단순한 색(주홍·쪽빛·황토·연두)을 얹은 판화 느낌. 전작 「영웅의 길」과 같은 계열이다. |
| 나 | `style_ink.png` | 수묵 담채풍 | 먹의 번짐과 옅은 채색, 넓은 여백으로 안개 낀 밤바다의 정서를 살린 그림. |
| 다 | `style_documentary.png` | 기록화풍 | 통신사 행렬도·화성능행도·왜관도처럼 높은 곳에서 내려다본 구도에 작은 배와 사람을 많이 그려 넣은 그림. 광물 안료 색감. |
| 라 | `style_picturebook.png` | 현대 그림책풍 | 전통 색을 쓰되 과슈·색연필 느낌으로 부드럽고 따뜻하게 그린 요즘 그림책 그림. 청소년이 보기 편하다. |

- `style_compare.png`: 네 장을 2×2로 모아 놓은 비교 그림(가·나·다·라 표시는 그림 바깥 여백에 있다).

## 고르는 방법

마음에 드는 화풍을 고르면 그 결과를 이 폴더의 `선택.md`에 적는다. 고른 화풍을 기준으로 이후 장면 그림·인물 그림을 만든다.
