- 만든 방법: `python tools/make_prompts.py` → `tools/genqueue.ps1`(Codex CLI image_gen, 모델 gpt-6-astra) → `python tools/process_assets.py`
- 참조 그림: 장면은 `design/style-samples/style_picturebook.png`(화풍 참조, style), 초상은 HUD 초상 `assets/ui/hud_okyoung.webp`(옥영은 same, 나머지는 style).

- 검수 기준: 같은 그림책 화풍인가 / 인물 옷차림이 도트 인물·HUD와 맞는가 / 그림 속 글자·낙관·서명이 없는가 / 피·주검·자해 장면이 없는가 / 캡션과 맞는가
