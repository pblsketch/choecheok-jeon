# 「두 개의 항로」 화면 미술 방향 (T14 시안, 2026-10-07)

> 고른 화풍: **현대 그림책풍**(구아슈 + 색연필, 쪽빛 밤과 등불빛, 전통 색). 기준 그림 `design/style-samples/style_picturebook.png`.
> 이 문서는 화면(UI)과 도트 맵 바닥에 그 화풍을 어떻게 옮기는지 정한다. 시안 사진은 `design/ui/시안/`.

## 1. 한 줄 방향

**밤바다 위 등불 하나.** 화면의 틀은 깊은 쪽빛 밤이고, 사람이 읽고 고르는 자리(대화·선택지·카드)는 등불에 비친 한지다.
강조색은 등불 주황 하나만 쓴다(누를 것, 지금 있는 곳, 얻은 것). 시험 틀처럼 보이는 회색·기본 단추·기본 스크롤 막대는 쓰지 않는다.

## 3. 결(질감)과 테두리

- **한지 결**: `assets/ui/paper.webp`(이음새 없게 손본 한지 무늬, 512px)를 한지 판 바탕에 깐다.
- **한지 판 테두리**: 먹빛 바깥선 2.5px + 안쪽 3px 띄우고 황토 색연필 선 1.5px(`--frame`) + 아래로 3px 먹 그림자(눌리는 판 느낌).
- **쪽빛 판**: 반투명 쪽빛 그러데이션 + 등불빛 실선 1.5px(`--plaque-line`) + 살짝 흐림(backdrop-filter).
- **게이지 막대**: 색연필 빗금(115°) 결을 얹고, 이름은 한자 한 글자를 담은 둥근 낙관.
- **장식은 마름모 등불 점 하나**(◆, 등불 주황). 미션·선택지·거점 첫 장에서만 쓴다.

## 4. 글꼴과 크기

- 본문·단추·HUD: **HangroBatang**(고운바탕 부분 글꼴, Regular/Bold — B단계에서 사용자가 고름). 화면 전체를 한 글꼴로 맞춰 그림책 본문처럼.
  고운바탕에 없는 한자(緣·生, 원문 한문)는 **HangroHanja**(Noto Serif KR 부분 글꼴)가 저절로 채운다.
- 제목·거점 이름·나라 이름: **HangroBrush**(나눔손글씨 붓 부분 글꼴). 붓 글꼴은 부분 글꼴에 든 글자(제목·거점 이름)에만 쓴다.
- 기준 크기: `html { font-size: clamp(13px, min(3.7vh, 1.75vw), 20px) }` → 휴대폰 가로 약 14px, PC 20px.

| 자리 | 크기 |
|---|---|
| 타이틀 제목 | 붓 `clamp(3.2rem, 14vh, 7rem)` |
| 거점 첫 장 이름 | 붓 3.1rem |
| 땅 이름 띠 | 붓 2.6rem + 명조 .9rem |
| 얻은 것 알림 | 명조 굵게 1.55rem |
| 본문·대사 | 명조 1.04~1.06rem, 줄 간격 1.75~1.85 |
| 선택지 제목 / 설명 | 명조 굵게 1rem / .8em |
| HUD 미션 / 목표 | 명조 굵게 .98rem / .8rem |

### 고지도

그림책풍 옛 지도 그림(글자 없음) 위에 거점 점·지명(명조)·나라 이름(붓)·뱃길(점선)·배를 얹는다.
카메라가 지금 오가는 거점과 뱃길이 다 보이게 지도를 옮기고 키운다. 뱃길 고르기는 아래 한지 판의 선택지, 고른 길은 등불빛 점선이 흐른다.

## 9. HUD 안전 여백(B단계)

- 카메라는 맵 위·아래 끝에서 위쪽 HUD 높이·아래쪽 조작부 높이만큼 더 물러설 수 있다(`G.world.safe`). 물러선 자리는 맵 가장자리를 거울처럼 비춰 어둡게 채운다.
- 머리 위 표시·이름표가 위쪽 HUD에 닿으면 발밑으로 내려 그린다. 목표가 HUD 밑이면 가장자리 화살표.
- 자동 점검(`tests/smoke.mjs`)이 휴대폰 가로·PC에서 맵 네 구석·위 가운데 끝의 사람이 HUD와 겹치지 않는지 본다.

## 10. 남은 확인

- (정함, 2026-10-08) HUD 초상과 대화 얼굴은 옥영의 지금 옷차림을 따라 네 벌(여복·남복·명나라 옷·조선 옷)로 바뀐다. 같은 얼굴, 같은 그림책풍.
- 대화 얼굴은 초상 그림이 생기기 전까지 도트 인물의 머리·어깨(옥영은 HUD 초상).
