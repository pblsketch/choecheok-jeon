# 보안·개인정보

## 무엇이 없는가

- 로그인·계정·서버·학생 기록 수집이 **없다**. 그래서 인증 흐름도, 서버 쪽 접근 제어도, 서버 감사 기록도 없다. 이것은 빠진 것이 아니라 설계다: 학생 한 명이 자기 기기 하나로 혼자 하고, 결과는 학생이 직접 이미지로 제출한다.
- 실행 중 외부로 나가는 요청이 없다. 게임을 올린 곳과 같은 출처의 정적 파일(상대 경로 GET)만 읽는다. 외부 CDN·웹 글꼴 서비스·분석 도구·오류 보고·광고 스크립트는 없고, 들이지 않는다. 들이면 학생 기기의 접속 정보가 제삼자에게 가므로 이 프로젝트의 개인정보 약속이 깨진다.
- 정적 파일을 서빙하는 곳(나중에 정할 배포처)의 일반 접속 기록(IP·시각·요청 주소)은 그 서버의 정책을 따른다. 게임 코드가 따로 남기는 것은 없다.

## 지키는 것

| 자산 | 어디에 | 민감도 |
|---|---|---|
| 학생 이름(반·번호 포함, 결과 화면 입력칸) | localStorage `choecheok-jeon-v1`의 `name` | 개인정보. 이 게임이 다루는 유일한 개인정보 |
| 진행 상태(게이지·선택·지식·카드·횟수·거점 기록·받은 이어 하기 글자·「김영철전」에서 고른 것) | 같은 칸 | 낮음(학습 기록) |
| 설정(방식·글자 크기·효과음·배경음·선생님용) | 같은 칸 | 없음 |
| 결과 이미지(PNG) | 학생이 저장한 그 기기의 내려받기 폴더 | 이름이 들어 있다. 학생이 직접 제출할 때만 밖으로 나간다 |
| 이어 하기 글자(6자) | 화면에 보이고 학생이 받아 적음 | 낮음. 개인정보를 담지 않는다(방식·1막 선택·지식·시구 맞추기 횟수만) |

- localStorage는 출처(scheme + host + port)마다 따로다. 같은 출처에 시리즈의 다른 게임을 함께 올리면 저장 공간을 같이 쓰게 된다. 칸 이름(`choecheok-jeon-v1`)이 달라 섞이지 않지만, 같은 출처의 다른 스크립트는 이 칸을 읽을 수 있다.
- 저장은 평문 JSON이다. 같은 기기·같은 브라우저를 쓰는 사람은 개발자 도구로 이름과 진행을 볼 수 있다.

## 누가 무엇을 할 수 있는가

| 주체 | 할 수 있는 것 | 할 수 없는 것 |
|---|---|---|
| 학생(그 기기·브라우저) | 놀기, 이름 적기, 결과 이미지 저장, 이어 하기 글자 받기·넣기, '처음부터'로 자기 기록 지우기, 설정 바꾸기(선생님용 포함) | 다른 기기의 기록 보기·바꾸기(서버가 없으므로 원래 불가) |
| 선생님용을 켠 사람 | 게이지 숫자 보기, 장면·목표 건너뛰기, 시구 '정답 보기', 수첩의 모든 카드와 '⚠ 검수' 거리 보기 | 위 학생과 같음. 다른 학생의 기록에 닿는 기능은 없다 |
| 같은 기기의 다음 사용자 | 앞사람이 '처음부터'를 누르지 않았으면 앞사람의 진행과 이름을 이어받는다 | — |

### 선생님용은 접근 제어가 아니다

- 선생님용은 주소 끝 `?teacher=1`이나 설정의 '선생님용 켜기'로 **누구나** 켤 수 있다. 비밀번호·확인이 없다.
- 켜면 저장의 설정 칸(`teacher: true`)에 남아, 끌 때까지 이어진다. 주소에서 `?teacher=1`을 빼도 꺼지지 않는다.
- '처음부터'는 설정을 남기므로 **선생님용도 남는다**. 선생님이 쓰던 공용 기기를 학생에게 넘길 때는 설정에서 선생님용을 꺼야 한다.
- 그러므로 선생님용 뒤에 숨겨도 되는 것은 '학생이 보면 재미가 줄어드는 것'(숫자, 정답, 미리 보기)뿐이다. 평가 정답·개인정보·납품 전용 자료처럼 학생이 보면 안 되는 것은 선생님용 뒤에 두지 않는다.

### 이어 하기 글자는 위조를 막지 않는다

- 글자의 검사 비트는 받아 적다 생긴 오타를 잡기 위한 것이다. 어느 한 글자를 바꾸면 반드시 거절되지만, 부호화 방식을 아는 사람은 원하는 1막 상태의 글자를 만들 수 있다.
- 글자로 되살린 결과는 학습 기록일 뿐 평가 근거로 쓰지 않는다는 전제다. 결과 이미지도 학생 기기에서 그려지므로 같은 전제다.

## 공용 기기와 지워지는 기록

| 동작 | 지우는 것 | 남기는 것 | 확인 |
|---|---|---|---|
| 타이틀 '처음부터' | 진행 전부, 이름 | 방식·글자 크기·효과음·배경음·선생님용 | 한 번 묻는다 |
| 이어 하기 글자 넣기(기록이 이미 있을 때) | 진행 전부를 글자의 1막 끝 상태로 바꿈 | 이름, 방식 외 설정 | 덮어쓸지 한 번 묻는다 |
| 주소 `?act=2`로 열기 | 진행 전부, 이름(그 주소로 시작한 2막을 하던 중이 아니면) | 설정 | **묻지 않는다** |
| 브라우저 기록 지우기·시크릿 창 닫기 | 전부 | — | 브라우저가 정함 |

- `?act=2` 주소를 학생에게 나누어 주면, 이미 1막을 한 학생의 진행과 이름이 확인 없이 지워진다. 학생이 2차시를 이어 갈 때는 같은 브라우저의 '이어 하기'나 이어 하기 글자를 쓴다.
- 이름은 결과 화면에서 적는 순간부터 기기에 남는다. 공용 기기에서는 결과 이미지를 저장한 뒤 '처음부터'를 누르는 것이 운영 규칙이다.

## 기록(감사)

- 기록하는 사건이 없다. 서버가 없어 누가 언제 무엇을 했는지 남길 곳이 없고, 기기 안에도 놀이 진행 외의 사용 기록을 남기지 않는다. 시작·끝 시각(`startedAt`·`finishedAt`)을 저장하지만 쓰는 곳은 결과 화면의 날짜 표시뿐이다.

## 바꿀 때 지킬 것

- 학생 정보를 기기 밖으로 보내는 기능(점수 전송, 공유 링크 생성, 클라우드 저장, 원격 오류 보고)을 넣는 것은 이 프로젝트의 개인정보 전제를 바꾸는 일이다. 넣기 전에 만든이의 결정이 필요하다.
- 결과 이미지·저장에 이름 외의 개인정보 입력칸(학교명·전화번호 등)을 더하지 않는다.
- 저장 칸 이름(`choecheok-jeon-v1`)을 바꾸면 기존 학생의 진행이 사라진 것처럼 보인다(옛 칸은 남아 있지만 읽지 않음).
