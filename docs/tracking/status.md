## 남은 것(우선순위 차례)

1. **퉁소 실제 연주 넣기** — 만든이의 손이 필요하다. 디지털 이음 단음 다운로드의 퉁소 「애원성」(`Tungso_8.wav`, 공공누리 제1유형)을 사용목적 '상업용'으로 내려받아 `assets/raw_audio/tongso/`에 넣으면 `python tools/make_tongso.py` → 크레딧 두 줄 → 점검. 그전까지 안남 퉁소는 합성음이고, 게임 안에서 그렇다고 밝힌다. 받을 수 없으면 단소 등 같은 조건의 실연으로 대신하고 "퉁소 대신 ○○ 연주"로 밝힌다.
2. **배경음 원음을 '상업용'으로 다시 받기** — 지금 배경음 9곡의 원음(악구 묶음 8가지)은 「영웅의 길」이 디지털 이음 내려받기 창에 '비상업용·교육용'으로 적고 받은 것이다. 이용 조건(공공누리 제1유형)은 상업 이용을 허락하므로 파일은 바뀌지 않지만, 납품 기록을 깔끔히 하려면 퉁소와 함께 '상업용'으로 다시 받는다.
3. **교사 검수** — README '교사 검수 목록'(= `design/research/01_원문_사실확인.md` §9)의 ⚠ 항목: 귀국 항해 결락 원문(인쇄본 확인), 낭고야 표기·위치, 사간/사우·송우/주우, 정답 시·화답시·원작 대조 카드의 자체 풀이, 함정 구절 A·B 열 개가 기존 구절과 겹치지 않는지, 역사 카드의 연도·병력·인물, 원작 옥영의 항로를 바다길에 가깝다고 본 것, EBS 연계 연도, 「김영철전」 구두점(한국고전번역원 표점본)의 이용 조건(만든이가 확인하기로 함, 그때까지 검수 거리) 등. 고칠 곳은 자료 파일만이다.
4. **배포 결정** — 지학사 사이트 탑재인지 공개 웹 주소(예: GitHub Pages)인지 정해지지 않았다. 지금 구조(상대 경로 정적 파일)로 어디든 올릴 수 있다. 정해지면 올리고, 올린 주소에서 휴대폰 가로·PC 확인.
5. **삽화의 알려진 흠** — '지친 귀향'에서 몽석이 방 안에서도 전립을 씀, '조선 배' 삽화의 배가 중국 정크선처럼 보임, 대화창의 옥영 초상이 남복 한 벌뿐(여복·조선 옷·명나라 옷 장면에서도 같음). `design/ui/삽화_검수.md`.
6. **실제 학생 플레이 뒤 조정** — 게이지 폭·결말 기준·플레이 시간은 자동 완주로만 맞췄다. 1막에서 연의 길만 고르면 낭고야에서 쓰러지는 대가, 안남 예외가 실제 선택으로는 일어나지 않는 점도 이때 함께 본다. 숫자는 `js/data/texts.js`·`js/data/places/sea.js`·`js/data/poem.js`.
7. **지학사 교과서 연계 범위에 따른 장면 조정** — 범위가 정해지면.
8. **「김영철전」 후속판** — 시리즈 제안서가 말한 후속 게임. 지금의 거점·게이지·대조 카드·결과 화면 틀을 재사용하는 것이 전제다.
