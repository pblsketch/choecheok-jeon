# 결정 기록

「두 개의 항로」를 만들며 다른 팀이라면 달리 골랐을 법한 선택들이다. 번호는 정한 차례다.

| 번호 | 결정 | 상태 | 한 줄 |
|---|---|---|---|
| [0001](0001-landscape-screen.md) | 가로 화면 기준 | 확정 | 시리즈 공통의 세로 화면 대신, 걷는 맵과 넓은 바다 지도를 위해 가로. 세로는 안내 한 장 |
| [0002](0002-four-ending-colors.md) | 결말은 재회의 빛깔 넷 | 확정 | 재회는 원작대로 반드시, 알아보는 장면과 후일담만 연·생에 따라 넷 |
| [0003](0003-fullscreen-map-corner-hud.md) | 전체 화면 맵 + 구석 HUD | 확정 | 맵/패널 분할은 시험 틀처럼 보여 거절됨. 그림책풍 '밤바다 위 등불 하나'로 통일 |
| [0004](0004-picture-book-style.md) | 현대 그림책풍, Codex 자체 생성 | 확정 | 시안 넷 가운데 만든이가 고름. 같은 화풍·같은 도구로만 그린다 |
| [0005](0005-boat-and-provisions-event.md) | '배와 양식 마련'(생 +2) 고정 사건 | 확정 | 원작대로 걸은 학생이 뱃길 앞에서 생 6이 되어 바다길을 고를 수 있게 |
| [0006](0006-prep-effect-only-at-joseon-ship.md) | 준비 효과는 조선 배에서만 | 확정 | 해적에게는 중국말로 넘기므로(원문), 준비는 조선 옷·조선말 구조 장면에만 |
| [0007](0007-resume-code-replay.md) | 이어 하기 글자는 고른 것만 담고 되풀이 | 확정 | 6자 = 21비트 상태 + 9비트 오타 검사. 더듬기는 정확히 담고 화면은 '7+' |
| [0008](0008-reuse-hero-engine.md) | 「영웅의 길」 엔진 복사·수정 | 확정 | 싸움 제외, 빌드 도구 없는 순수 JS. 원래 폴더는 읽기만 |
| [0009](0009-no-dream-during-annam-poem.md) | 안남 시구 맞추기 도중 꿈 없음 | 확정 | 재회 절정을 끊지 않게, 퉁소가 다시 울려 정답이 떠오름(생 0 유지, 횟수 그대로) |
