# 0004. 현대 그림책풍 화풍, Codex CLI 자체 생성

- 상태: 확정(만든이가 시안 넷 가운데 고름, 2026-10-07, `design/style-samples/선택.md`)

## 맥락
장면 삽화·대화 초상·타이틀·고지도는 모두 지학사에 상업 납품할 수 있어야 하고 한 화풍으로 맞아야 한다. 같은 만든이의 「영웅의 길」은 방각본 목판풍이었다. 만든이는 화풍을 미리 정하지 않고 같은 장면(안남 포구의 밤)을 네 화풍으로 그린 시안을 보고 고르기로 했다.

## 결정
네 시안(목판 삽화풍·수묵 담채풍·기록화(행렬도)풍·현대 그림책풍) 가운데 **현대 그림책풍**(구아슈 + 색연필, 쪽빛 밤과 등불빛, 전통 색)을 골랐다. 장면 삽화 54장·초상 20장·타이틀·고지도·HUD 초상·한지 무늬를 모두 Codex CLI 이미지 생성으로 이 화풍(기준 그림 `design/style-samples/style_picturebook.png`를 참조)으로 만들었다. 도트 인물·소품은 화풍과 별개로 「영웅의 길」과 같은 탑뷰 도트다.

## 버린 안
- 목판 삽화풍: 「영웅의 길」과 겹쳐 시리즈 안에서 구별되지 않고, 밤바다·등불 같은 이 작품의 정서를 담기 어렵다.
- 수묵 담채풍·기록화풍: 시안 비교에서 만든이가 고르지 않았다.
- 다른 이미지 생성 도구나 외부 그림(스톡·공개 그림): 이용 조건 확인이 어렵거나 화풍이 섞인다.

## 결과
- 그림을 더하거나 다시 그릴 때는 같은 화풍·같은 도구로만 한다. 생성이 막히면 다른 도구로 바꾸지 않고 만든이에게 알린다.
- 이 계정에서 Codex 기본 모델로는 생성이 되지 않아 `HERO_CODEX_MODEL=gpt-6-astra`(또는 `-UseModel`)를 늘 지정한다. 프롬프트는 영어 ASCII만, 그림 안에 글자 없음.
- 그림의 작은 흠(전립을 쓴 실내, 조선 배가 정크선처럼 보임)은 같은 방법으로 다시 그려야만 고칠 수 있다.
